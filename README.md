# Heliora

Explore the Solar System, fully offline. Heliora shows all eight planets in a 2D orbit map and as rotating 3D globes, with facts about each planet's atmosphere and how much oxygen it has.

Part of [Lumio Apps](https://github.com/lumio-apps): no ads, no account, no tracking.

## Features

- **2D and 3D views**: a moving top-down map of the Solar System, and 3D planets you can rotate and zoom. Switch with the 2D / 3D button.
- **Sun, Pluto, the Moon and 7 other major moons**: Io, Europa, Ganymede, Callisto, Titan, Enceladus and Triton, each with its own page and 3D globe.
- **Could humans live here?**: a simple 0 to 10 life score for every body, from temperature, air pressure, oxygen, water, surface and gravity.
- **Planet facts**: diameter, gravity, temperature, length of day and year, known moons, distance from the Sun and surface pressure.
- **Atmosphere and oxygen**: what each atmosphere is made of, and how its oxygen compares with Earth's.
- **Compare**: any two planets side by side.
- **Weight**: what you would weigh on every planet.
- **Quiz**: 10 questions built from the planet data, with a best score.
- **Light, dark or system theme.**
- **20 languages**: English, Hindi, Bengali, Gujarati, Kannada, Malayalam, Marathi, Punjabi, Tamil, Telugu, Urdu, Arabic, Chinese, Japanese, Spanish, French, Portuguese, Russian, Indonesian and Armenian.
- **In-app update check** from GitHub Releases. Settings are kept when you update.

## Privacy

Heliora works without internet. The only network request is the optional update check, which asks GitHub for the latest release and sends nothing about you. It can be turned off in Settings.

## Data

Planet facts come from the [NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/). Moon counts are NASA's known moons as of mid 2026. The 3D surfaces are generated by a shader, so the app needs no image files.

## Build

```
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
flutter build apk --release
```

Releases are built by GitHub Actions when a version tag such as `v1.0.0` is pushed (see `.github/workflows/release.yml`).

## Translations

Texts live in `lib/l10n/app_<language>.arb`. To fix a translation, edit the matching file and open a pull request.
